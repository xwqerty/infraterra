# AdScreen Platform Deployment Guide

This guide provides step-by-step instructions for deploying the AdScreen platform, including the AWS infrastructure, web application, and PC Stick client software.

## Prerequisites

- AWS Account with appropriate permissions
- AWS CLI installed and configured with your credentials
- Node.js 14+ and npm
- Terraform 1.0+
- Git

## 1. Clone the Repository

```bash
git clone https://github.com/your-org/adscreen-platform.git
cd adscreen-platform
```

## 2. Deploy AWS Infrastructure

### Set Up Terraform

```bash
cd terraform

# Initialize Terraform
terraform init

# Review the Terraform plan
terraform plan

# Apply the Terraform configuration
terraform apply
```

When prompted, type `yes` to confirm the deployment.

### Note the Outputs

After Terraform completes, note the following outputs:
- `api_endpoint`: The API Gateway endpoint URL
- `iot_endpoint`: The AWS IoT Core endpoint URL
- `ad_content_bucket`: The S3 bucket name for ad content storage

These values will be needed for the frontend and PC Stick client configuration.

## 3. Package and Deploy Lambda Functions

```bash
# Make the packaging script executable
chmod +x scripts/package-lambdas.sh

# Package the Lambda functions
./scripts/package-lambdas.sh

# Re-apply Terraform to deploy the Lambda functions
cd terraform
terraform apply
```

## 4. Seed Initial Data

```bash
# Install dependencies
cd scripts
npm install uuid aws-sdk

# Make the script executable
chmod +x seed-data.js

# Run the script
./seed-data.js
```

Follow the prompts to set up your region, project name, and environment. The script will create:
- A demo user account
- Sample screen locations
- A sample advertisement (if you provide a sample-ad.jpg file)

## 5. Configure and Deploy the Web Frontend

```bash
cd frontend

# Install dependencies
npm install

# Create .env file with API endpoint
echo "REACT_APP_API_ENDPOINT=$(terraform output -raw api_endpoint)" > .env

# Build the web application
npm run build

# Deploy to S3 (if using S3 hosting)
aws s3 sync build/ s3://your-frontend-bucket/
```

Alternatively, you can host the frontend on any web hosting service of your choice.

## 6. Set Up PC Stick Devices

### Register a New Screen

```bash
cd scripts
npm install

# Make the script executable
chmod +x setup-screen.js

# Run the screen setup utility
./setup-screen.js
```

Follow the prompts to register a new screen. The script will:
1. Call the API to register the screen
2. Save the IoT certificate and private key
3. Generate a configuration file
4. Optionally create a QR code for easy setup

### Deploy the PC Stick Client

For each PC Stick device:

1. Install on the PC Stick:
   ```bash
   cd pc-stick-client

   # Install dependencies
   npm install

   # Build the application for Windows or Linux
   npm run build:win
   # or
   npm run build:linux
   ```

2. Copy the installer to the PC Stick and run it.

3. Configure the client:
   - Either manually enter the screen ID, certificate, and IoT endpoint
   - Or scan the QR code generated by the setup script

4. The client will automatically connect to AWS IoT and begin displaying ads.

## 7. Verify the Deployment

1. Access the web application via your hosting URL.
2. Log in using the demo credentials (demo@adscreen.example).
3. Verify the sample screens are listed.
4. Upload a new advertisement and schedule it on a screen.
5. Verify that the PC Stick receives and displays the advertisement.

## Cost Optimization Tips

- **Scale down in development**: Use smaller instance sizes or serverless services.
- **Clean up test data**: Remove test files from S3 to save storage costs.
- **Monitor usage**: Set up CloudWatch alarms to monitor and notify about unexpected costs.
- **DynamoDB capacity**: Start with on-demand pricing for low volume, then switch to provisioned capacity when you understand your usage patterns.

## Troubleshooting

### Common Issues

1. **API Gateway errors**:
   - Check Lambda function logs in CloudWatch
   - Verify API Gateway CORS configuration

2. **IoT connectivity issues**:
   - Verify certificates are properly installed
   - Check IoT policy permissions
   - Ensure the PC Stick has internet connectivity

3. **Advertisement not appearing on screen**:
   - Check the schedule dates and times
   - Verify the content was successfully uploaded to S3
   - Check IoT messages in CloudWatch Logs
   - Restart the PC Stick client application

### Logs and Monitoring

- Lambda function logs are available in CloudWatch
- IoT Core logs can be enabled for debugging device connectivity
- PC Stick client logs are stored locally in the application's user data directory

## Security Considerations

- Rotate IoT certificates periodically
- Implement additional authentication for production use
- Restrict S3 bucket policies to prevent unauthorized access
- Implement content moderation for advertisement uploads
